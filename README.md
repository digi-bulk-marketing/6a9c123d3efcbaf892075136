# Popeye Email Sender

Popeye Email Sender by popeye marketing.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/6a9c123d3efcbaf892075136/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **Popeye Email Sender** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/6a9c123d3efcbaf892075136/releases/latest) and reinstall.
